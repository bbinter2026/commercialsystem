# commercialsystem
Sistema Comercial offline para criar, editar, guardar e imprimir documentos comerciais em formato Letter. Inclui faturas, recibos, cotações e faturas pró-forma, cálculo de impostos, dados bancários, histórico local, exportação/importação JSON, personalização de logótipo e fundo, autenticação local e suporte a Português, Inglês, Espanhol e Francês..
